# Frontend for LLM-Powered Content Summarizer

This React application allows the user to input text, submit it to the backend API, and displays the summarized text returned from the LLM service.

## Files description

- src/App.jsx: Main React component with form and result display
- src/api.js: Module for backend API calls
- src/App.test.jsx: Tests component UI and API interaction

## Installation

From the frontend directory:

    npm install
    npm start


## Running tests

    npm test
